# Deployment / 部署

[English deployment guide](../../docs/deployment.md) · [中文部署說明](../../docs/deployment.zh-Hant.md)

Run Docker Compose from the repository root. Runtime credentials and data are stored in persistent named volumes, not in this directory.

請在倉庫根目錄執行 Docker Compose。執行憑據和資料儲存在持久卷中，不儲存在本目錄。
