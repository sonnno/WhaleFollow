# Security / 安全问题

Use GitHub's private vulnerability reporting for this repository:

[Report a vulnerability privately](https://github.com/sonnno/WhaleFollow/security/advisories/new)

Please include affected versions, reproduction steps, impact and a minimal proof of concept. Remove private keys, tokens, runtime credentials and unrelated personal data. Do not disclose credentials or an unpatched exploitable issue in public Issues or pull requests.

请通过上方链接私下报告安全问题，包含受影响版本、复现步骤、影响和最小验证方法。请先移除私钥、令牌、运行凭据及无关个人信息；不要在公开 Issue 或 PR 中发布凭据或尚未修复的可利用漏洞。

Security fixes target the latest release and `main`. There is no guaranteed response time or bug bounty. This project is intended for a single administrator; restrict dashboard access and use HTTPS. Even a paper deployment contains login credentials and account history that should remain private.

安全修复面向最新版本及 `main`。项目不承诺固定响应时间或漏洞奖励。后台供单管理员使用，应限制访问来源并使用 HTTPS；虚拟部署也包含需要保护的登录信息及账户历史。
